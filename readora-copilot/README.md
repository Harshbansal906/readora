# Readora — Google Antigravity & CopilotKit Integration

This module connects **Google Antigravity** to **Readora** using `@copilotkit/react-ui` on the frontend and the `ag-ui-antigravity` Python adapter backend over the **Agent-User Interaction Protocol (AG-UI)**.

---

## Architecture Overview

```
┌─────────────────────────────────┐
│ Readora Next.js / React Frontend│
│   <CopilotKit runtimeUrl="..."> │
│   <CopilotSidebar />            │
│   useCopilotReadable / Action   │
└────────────────┬────────────────┘
                 │ AG-UI Protocol (HTTP / SSE)
                 ▼
┌─────────────────────────────────┐
│ Python FastAPI Backend          │
│   ag-ui-antigravity             │
│   create_antigravity_app()      │
│   AntigravityAgent (Gemini 2.5) │
└────────────────┬────────────────┘
                 │ Tool Execution
                 ▼
┌─────────────────────────────────┐
│ Readora Editorial Tools         │
│   • draft_article               │
│   • review_article_prose        │
│   • suggest_topics_and_headlines│
└─────────────────────────────────┘
```

## 1. Quickstart — Backend (FastAPI + AG-UI Adapter)

### Prerequisites:
- Python 3.10 – 3.14 (Python 3.12 recommended)
- `GEMINI_API_KEY` configured in `.env` or system environment

### Setup & Run:
```bash
# 1. Install required packages
py -3.12 -m pip install ag-ui-antigravity fastapi uvicorn

# 2. Run the agent server on port 8000
py -3.12 -m uvicorn agent_server:app --host 0.0.0.0 --port 8000 --reload
```

The AG-UI endpoint will be live at:
- `http://localhost:8000/copilotkit` (Endpoint for CopilotKit `runtimeUrl`)
- `http://localhost:8000/copilotkit/capabilities` (AG-UI capabilities declaration)
- `http://localhost:8000/health` (Health check)

---

## 2. Quickstart — Frontend (Next.js / React App)

### Setup & Run:
```bash
cd readora-copilot
npm install
npm run dev
```

The application runs at:
- `http://localhost:3000`

### Features Included:
1. **Real-time Streaming:** Every token and thought generated by Google Antigravity streams live into `<CopilotSidebar>`.
2. **Generative UI (`useCopilotAction`):**
   - Outlines and drafted articles render as interactive preview cards with an **"Apply Draft to Editor"** button.
   - Editorial critiques render as custom rubrics with score breakdown, pacing feedback, and actionable guidance.
3. **Editor Context Awareness (`useCopilotReadable`):**
   - Automatically synchronizes the active essay title, deck, word count, and text with the Antigravity agent.
